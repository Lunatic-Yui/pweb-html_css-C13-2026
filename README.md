## 🌐 Deskripsi

Website ini terdiri dari 3 halaman yang saling terhubung, menampilkan rekam jejak kepemimpinan SBY dalam format portofolio modern:

1. **Beranda** (`html_bab 1.html`) — landing page perkenalan tokoh
2. **Kinerja & Warisan** (`html_bab 1n.html`) — rangkuman 11 bidang kebijakan & program (ekonomi, infrastruktur, kesehatan, pendidikan, perdamaian Aceh, diplomasi, dsb.)
3. **Creative CV** (`html_bab 1t.html`) — riwayat hidup, pendidikan, karier militer & pemerintahan, keahlian, dan sisi personal

## ✅ Elemen CSS yang Digunakan (sesuai requirement modul)

- **Pseudo-Class** — `:hover`, `:focus-visible`, `:checked` (untuk menu hamburger mobile tanpa JavaScript)
- **Position** — `sticky` (navbar), `relative` & `absolute` (dekorasi, badge, timeline, diagram)
- **Display** — `flex` (navbar, stat, flow steps) dan `grid` (kartu proyek, kartu info)
- **Flexbox** — layout navigasi, kartu fitur, carousel
- **Grid** — grid kartu proyek infrastruktur, grid statistik ringkasan
- **Responsive** — media query untuk tampilan PC, tablet, dan HP
